Ejercicios Prácticos

Practica lo aprendido con ejercicios organizados por módulo. Autocorregibles y con soluciones incluidas.

Ejercicios HTML

1. Crear una Página de Perfil

Crea una página HTML con tu perfil personal: foto, nombre, descripción, lista de habilidades y enlaces a redes sociales.

Básico ⏱️ 20 min

2. Formulario de Contacto Completo

Construye un formulario con: nombre, email, asunto (select), mensaje (textarea), checkbox de términos y botón de envío.

Intermedio ⏱️ 30 min

3. Estructura Semántica de Blog

Crea la estructura HTML de un blog usando etiquetas semánticas: header, nav, main, article, aside, footer.

Avanzado ⏱️ 40 min

Ejercicios CSS

4. Card Component

Crea una card con imagen, título, descripción y botón. Debe tener hover effect, sombras y border-radius.

Básico ⏱️ 25 min

5. Navbar Responsive con Flexbox

Construye un navbar que en desktop muestre links horizontales y en móvil se convierta en menú hamburguesa.

Intermedio ⏱️ 45 min

6. Galería con CSS Grid

Crea una galería de imágenes responsive usando CSS Grid. Debe adaptarse automáticamente al tamaño de pantalla.

Avanzado ⏱️ 50 min

7. Dark Mode Toggle

Implementa un sistema de dark mode usando CSS variables y localStorage para persistir la preferencia.

Avanzado ⏱️ 60 min

Ejercicios JavaScript

8. Calculadora Simple

Crea una calculadora que realice operaciones básicas: suma, resta, multiplicación y división.

Básico ⏱️ 30 min

9. To-Do List App

App de tareas con agregar, marcar como completada, eliminar y guardar en localStorage.

Intermedio ⏱️ 60 min

10. Buscador con Filtros

Crea un buscador que filtre una lista de items en tiempo real según el texto ingresado.

Intermedio ⏱️ 45 min

11. Weather App con API

Consume la API de OpenWeatherMap para mostrar el clima de una ciudad. Practica fetch y async/await.

Avanzado ⏱️ 90 min

Ejercicios Astro

12. Blog Personal con Astro

Crea un blog usando Content Collections, con listado de posts, página individual y categorías.

Intermedio ⏱️ 120 min

13. Landing Page con React Islands

Construye una landing page en Astro con componentes React interactivos (contador, formulario, carousel).

Avanzado ⏱️ 150 min

14. Portfolio con TypeScript

Crea tu portfolio en Astro + TypeScript con secciones: sobre mí, proyectos, habilidades, contacto.

Avanzado ⏱️ 180 min

💡 Consejos para los Ejercicios

Intenta primero solo

No veas la solución de inmediato. El error es parte del aprendizaje.

Usa la consola

F12 en el navegador te mostrará errores y permitirá debuggear.

Investiga

Si te atascas, busca en MDN, Stack Overflow o pregunta a la comunidad.

Experimenta

Modifica los ejercicios, añade funcionalidades extra, hazlos tuyos.
