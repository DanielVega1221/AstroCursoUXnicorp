Módulo 1

Fundamentos de Programación

Comienza tu viaje en el desarrollo web entendiendo los conceptos fundamentales de la programación y cómo funciona la web.

¿Qué es Programar?

Programar es el arte de dar instrucciones precisas a una computadora para que realice tareas específicas. Es como escribir una receta de cocina, pero para una máquina.

Piensa en la computadora como un asistente muy literal que hace exactamente lo que le dices, ni más ni menos. Si olvidas un paso o te equivocas en una instrucción, la computadora se confundirá o dará un error.

💡 Analogía del Café:

✓ Humano:

"Prepara café"

Entiende el contexto, sabe todos los pasos

✓ Computadora:

"1. Toma taza
2. Pon 200ml agua
3. Añade 15g café
4. Calienta a 95°C
5. Espera 4 minutos"

Necesita instrucciones precisas

Lo bueno: Una vez que la computadora sabe hacer algo, puede repetirlo miles de veces sin cansarse ni equivocarse. ¡Y súper rápido!

Conceptos Clave de Programación

Estos son los 4 pilares fundamentales que encontrarás en todos los lenguajes de programación:

📦 Variables

Cajas con etiquetas que guardan información.

Ejemplo del mundo real:
Como poner dinero en un sobre y escribir "Ahorro" en él. Luego puedes abrir ese sobre y usar el dinero.

🏷️ Tipos de Datos

Diferentes tipos de información que guardas.

Ejemplo:
• Texto: "Hola"
• Número: 25
• Verdadero/Falso: ¿Está lloviendo? No

🔀 Condicionales

Tomar decisiones basadas en condiciones.

Ejemplo del mundo real:
"Si llueve, lleva paraguas. Si no llueve, no lo lleves."

🔁 Bucles

Repetir una acción automáticamente.

Ejemplo del mundo real:
"Por cada estudiante en la clase, entrégale una hoja." En vez de decir 30 veces "Entrega hoja a Juan, entrega hoja a María..."

👀 Primer Vistazo al Código

No te preocupes si esto parece confuso al principio. Es normal. Nadie entiende código la primera vez que lo ve. Vamos a explicar cada línea:

Los 3 Pilares de la Web

Para crear una página web necesitas 3 lenguajes. Cada uno hace algo diferente, pero trabajan juntos.

Piénsalo así: HTML es el contenido (texto, imágenes), CSS es la decoración (colores, tamaños), y JavaScript es la interactividad (botones que funcionan, animaciones).

📄

HTML

Estructura
El esqueleto de la página.

Define QUÉ hay:
Títulos, párrafos, imágenes, enlaces, botones...
🎨

CSS

Estilo
La apariencia visual.

Define CÓMO se ve:
Colores, tamaños, fuentes, posiciones, animaciones...
⚡

JavaScript

Comportamiento
La interactividad.

Define QUÉ puede hacer:
Responder a clicks, validar formularios, cargar datos, animar...

🏗️ Analogía Completa de una Casa:

HTML = Estructura

Las paredes, puertas, ventanas, habitaciones. La casa básica sin decorar.

CSS = Decoración

Pintura, muebles, cortinas, alfombras. Hace que la casa se vea bonita.

JavaScript = Funcionalidad

Interruptores de luz, puertas automáticas, alarmas. Hace que las cosas funcionen.

💡 Los tres juntos crean una página web completa y funcional

¿Cómo funciona un Navegador?

Un navegador (Chrome, Firefox, Safari...) es un programa que:

  1. 📥 Pide archivos a un servidor (HTML, CSS, JS, imágenes...)
  2. 🔍 Lee el HTML y construye el DOM (Document Object Model)
  3. 🎨 Aplica el CSS para darle estilo
  4. ⚡ Ejecuta JavaScript para hacerlo interactivo
  5. 🖥️ Muestra la página en pantalla

El DOM: Árbol de Objetos

Document
  └─ html
      ├─ head
      │   ├─ title
      │   └─ style
      └─ body
          ├─ h1 (texto: "Hola Mundo")
          ├─ p (texto: "Bienvenido")
          └─ button (texto: "Click")

El DOM es la representación en memoria de tu página HTML. JavaScript puede modificarlo para cambiar contenido, estilos o agregar elementos dinámicamente.

¿Cómo funciona Internet?

El Ciclo Request → Response

1
Cliente hace una petición (Request)

Tu navegador envía: "Quiero ver ejemplo.com"

2
DNS traduce el nombre a IP

"ejemplo.com" → 192.0.2.1

3
Servidor procesa y responde (Response)

Envía archivos HTML, CSS, JS, imágenes...

4
Navegador muestra la página

Renderiza HTML + CSS, ejecuta JS

¿Qué es una API?

Una API (Application Programming Interface) es como un camarero en un restaurante:

  • 🍽️ Tú (cliente) le pides algo específico
  • 📝 El camarero lleva tu pedido a la cocina (servidor)
  • 🍕 La cocina prepara la comida (datos)
  • ✅ El camarero te trae lo que pediste

Ejemplo real: Una app del clima pide datos a una API meteorológica, y esta responde con temperatura, pronóstico, etc.

⚠️ Errores Comunes de Principiantes

Confundir = con ==

= asigna un valor. == compara valores.

Olvidar punto y coma o llaves

JavaScript es estricto con la sintaxis. Un error pequeño puede romper todo.

No revisar la consola del navegador

Presiona F12 en tu navegador. La consola muestra errores y mensajes útiles.
