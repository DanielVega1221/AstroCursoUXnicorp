JavaScript: Básico a Intermedio

Aprende el lenguaje que da vida a la web. Desde variables hasta manipulación del DOM y programación asíncrona.

Sintaxis Básica

Variables

Las variables almacenan datos que puedes usar y modificar. Usa const por defecto (no cambia), let si necesitas reasignar, y evita var (obsoleto).

🟢 const - No se puede reasignar (usa esto por defecto)

🟡 let - Se puede reasignar (para contadores, estados)

🔴 var - Antiguo, tiene problemas de scope. NO USAR.

Manipulación del DOM

El DOM (Document Object Model) es la representación en JavaScript del HTML de tu página. Puedes modificarlo para cambiar contenido, estilos o estructura dinámicamente.

🌳 ¿Qué es el DOM?

Imagina que tu HTML es un árbol. El DOM convierte cada etiqueta en un "nodo" que JavaScript puede manipular.

document

  └─ <html>

     ├─ <head>

     └─ <body>

         ├─ <h1>Título</h1>

         └─ <p>Párrafo</p>

Seleccionar Elementos

El primer paso es seleccionar el elemento HTML que quieres modificar. Hay varios métodos:

Por ID (único)

getElementById('miId')

Para un elemento específico

Por Clase (múltiples)

getElementsByClassName('miClase')

Para varios elementos

Query Selector (CSS)

querySelector('.miClase')

Usa selectores CSS (recomendado)

Query Selector All

querySelectorAll('.miClase')

Todos los elementos que cumplan

⚡ JavaScript Cheat Sheet

Variables

const nombre = "Juan"; - No cambia

let edad = 25; - Puede cambiar

var viejo; - ❌ No usar

Tipos de Datos

string - "texto"

number - 42, 3.14

boolean - true, false

null - sin valor

undefined - no definido

Operadores

Aritméticos:

+ - * / %

++ incremento

-- decremento

Comparación:

=== igual estricto

!== diferente

> < >= <=

Lógicos:

&& AND

|| OR

! NOT

Condicionales

if (condicion) { // código } else { // código }
condicion ? verdadero : falso
switch (valor) { case 1: break; default: break; }

Bucles

for (let i = 0; i < 10; i++) { }
while (condicion) { }
array.forEach(item => { })

Funciones

function nombre(param) { return resultado; }
const nombre = (param) => resultado;

Arrays

const arr = [1, 2, 3];

arr.push(4) - Agregar al final

arr.pop() - Quitar último

arr.map(x => x * 2)

arr.filter(x => x > 2)

arr.find(x => x === 2)

arr.length - Tamaño

Objetos

const obj = { clave: valor };

obj.clave - Acceder

obj["clave"] - Alternativa

Object.keys(obj)

Object.values(obj)

{...obj} - Spread
