Módulo 2

HTML desde Cero

Domina el lenguaje de marcado que estructura toda la web. Aprende desde lo básico hasta HTML semántico moderno.

¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje que estructura el contenido de las páginas web. Es como el esqueleto de una casa: define dónde va cada cosa.

HTML usa etiquetas (también llamadas "tags") que son como cajas o contenedores. Cada etiqueta le dice al navegador: "esto es un título", "esto es un párrafo", "esto es una imagen", etc.

🎯 Piénsalo así:

Imagina que estás organizando una habitación y tienes diferentes cajas etiquetadas: "ROPA", "LIBROS", "JUGUETES". HTML hace lo mismo pero con contenido web.

📦 ¿Qué son las Etiquetas?

Las etiquetas HTML se escriben entre símbolos < y > (menor que y mayor que). La mayoría tienen una etiqueta de apertura y una de cierre.

✓ Etiqueta de Apertura

<p>

Dice: "aquí empieza un párrafo"

✓ Etiqueta de Cierre

</p>

Dice: "aquí termina el párrafo"

💡 Ejemplo Completo:

<p>Este es mi párrafo</p>

El texto "Este es mi párrafo" está entre la apertura y el cierre, como un sandwich donde el contenido está entre dos rebanadas de pan.

Estructura Básica de una Página HTML

Toda página HTML tiene la misma estructura básica. Es como una plantilla que siempre es igual, no importa qué página hagas. Piensa en esto como el esqueleto de una casa: todas las casas tienen cimientos, paredes y techo. Todas las páginas web tienen la misma estructura básica.

📋 Antes de ver el código, entiende las partes:

1. La Declaración (DOCTYPE)

Le dice al navegador: "Hola, esto es un documento HTML moderno". Es como decir "Hablo español" antes de empezar a hablar.

2. La Etiqueta HTML Principal

Es el contenedor más grande. Todo tu documento va dentro de esta etiqueta. Es como la casa completa que contiene todas las habitaciones.

3. La Cabeza (HEAD)

Información sobre tu página que NO se ve en la pantalla. Como el título de la pestaña del navegador, o instrucciones para Google. Es como los planos de una casa: importantes pero invisibles.

4. El Cuerpo (BODY)

TODO lo que SE VE en tu página va aquí: textos, imágenes, botones, videos. Es como el interior de la casa donde vives y pones tus muebles.

Ahora veamos el código completo con cada línea explicada:

estructura-basica.htmlhtml
1<!DOCTYPE html>
2<html lang="es">
3<head>
4  <meta charset="UTF-8">
5  <meta name="viewport" content="width=device-width, initial-scale=1.0">
6  <title>Mi Primera Página</title>
7</head>
8<body>
9  <h1>¡Hola Mundo!</h1>
10  <p>Este es mi primer documento HTML.</p>
11</body>
12</html>

🔍 Explicación línea por línea:

Línea 1:
<!DOCTYPE html>

Le dice al navegador: "Este es un documento HTML5 moderno"

Línea 2:
<html lang="es">

Abre la etiqueta HTML principal. lang="es" significa que la página está en español (importante para Google y lectores de pantalla)

Línea 3:
<head>

Abre la cabeza: información sobre la página

Línea 4:
<meta charset="UTF-8">

Dice qué caracteres puede usar (UTF-8 = todos los idiomas: español con ñ, emojis, etc.)

Línea 5:
<meta name="viewport"...>

Hace que tu página se vea bien en celulares y tablets (ajusta el zoom automáticamente)

Línea 6:
<title>Mi Primera Página</title>

El texto que aparece en la pestaña del navegador (arriba). También lo que aparece en Google cuando buscan tu página.

Línea 7:
</head>

Cierra la cabeza. Ya terminaste la información invisible.

Línea 8:
<body>

Abre el cuerpo. A partir de aquí, TODO se verá en la pantalla.

Línea 9:
<h1>¡Hola Mundo!</h1>

Un título grande (h1 = heading 1 = título nivel 1). Es el título más importante de tu página.

Línea 10:
<p>Este es mi primer documento HTML.</p>

Un párrafo de texto normal. "p" viene de "paragraph" (párrafo en inglés).

Línea 11:
</body>

Cierra el cuerpo. Ya terminaste el contenido visible.

Línea 12:
</html>

Cierra el documento completo. Fin de tu página web.

<head>

Información sobre la página (no visible): título, metadatos, estilos...

<body>

El contenido visible de la página: textos, imágenes, botones...

Etiquetas Fundamentales

Títulos y Textos

📚 ¿Qué son los títulos y para qué sirven?

Imagina que estás leyendo un libro. Los libros tienen:

  • ✅ Un título principal (el nombre del libro en la portada)
  • ✅ Títulos de capítulos (más pequeños que el título principal)
  • ✅ Subtítulos dentro de cada capítulo (aún más pequeños)
  • ✅ Párrafos de texto (el contenido que lees)

HTML funciona exactamente igual. Tienes 6 niveles de títulos:

<h1>

El título MÁS importante. Como el título de un libro. Solo usa UNO por página.

Ejemplo: "Mi Página Personal"

<h2>

Título de sección. Como capítulos de un libro.

Ejemplo: "Sobre Mí", "Mis Proyectos"

<h3>

Subtítulo dentro de una sección.

Ejemplo: "Experiencia Laboral" dentro de "Sobre Mí"

<h4>, <h5>, <h6>

Títulos más pequeños para subdivisiones.

Raramente se usan, pero están disponibles

⚠️ Regla de Oro:

Usa solo UN <h1> por página (el título principal). Luego puedes tener muchos <h2>, <h3>, etc. Es como tener un solo título en la portada del libro, pero muchos capítulos dentro.

Los párrafos <p> son para el texto normal. Es el contenido que la gente lee. Piensa en los párrafos de un artículo de periódico o un libro.

👁️ Así se ven los diferentes tamaños:

h1 - Título Principal (MUY GRANDE)

h2 - Subtítulo (grande)

h3 - Sección (mediano)

h4 - Subsección (normal+)

p - Párrafo de texto normal (para leer)

Ahora veamos cómo escribir esto en código:

titulos.htmlhtml
1<!-- Títulos: de h1 (más grande) a h6 (más pequeño) -->
2<h1>Título Principal</h1>
3<h2>Subtítulo</h2>
4<h3>Sección</h3>
5 
6<!-- Párrafos -->
7<p>Este es un párrafo normal.</p>
8<p>Cada etiqueta &lt;p&gt; crea un nuevo párrafo.</p>
9 
10<!-- Énfasis -->
11<p>Texto <strong>en negrita</strong> y texto <em>en cursiva</em>.</p>
12<p>También puedes <mark>resaltar</mark> o <del>tachar</del> texto.</p>

🎨 Cómo darle estilo al texto:

<strong>texto</strong>

Hace el texto en negrita

Úsalo para palabras IMPORTANTES

<em>texto</em>

Hace el texto en cursiva

Úsalo para dar énfasis suave

<mark>texto</mark>

Resalta el texto con color amarillo

Como usar un marcador fluorescente

<del>texto</del>

Tacha el texto: eliminado

Para mostrar que algo fue borrado

💡 Ejemplo completo:

<p>Este es <strong>muy importante</strong> y esto <em>tiene énfasis</em>.</p>

Se verá así: Este es muy importante y esto tiene énfasis.

Enlaces e Imágenes

🔗 ¿Qué son los enlaces?

Los enlaces son como puertas que te llevan a otros lugares. Cuando haces clic en un enlace (link), te transporta a otra página web.

Piensa en un enlace como:

  • 🚪 Una puerta - Te lleva de un lugar a otro
  • 📖 Una referencia de libro - "Ve a la página 42"
  • 🗺️ Una señal de tráfico - Te indica hacia dónde ir

La etiqueta para crear enlaces es <a> (de "anchor" = ancla en inglés). Tiene dos partes importantes:

href=""

La dirección a donde lleva el enlace

Es como la dirección de una casa: le dices al navegador a dónde ir

El texto dentro

Lo que ve y hace clic el usuario

Es como el letrero de la puerta: "Haz clic aquí"

🖼️ ¿Qué son las imágenes?

Las imágenes muestran fotos, dibujos, logos, etc. en tu página web. Es como pegar una foto en un álbum.

La etiqueta es <img> y tiene algo especial: NO tiene etiqueta de cierre. Es una etiqueta "auto-cerrada" porque no necesita envolver contenido.

Partes importantes de una imagen:

📍
src=""

La ubicación de la imagen (dónde está guardada)

Como decir: "La foto está en la carpeta 'imagenes/foto.jpg'"

📝
alt=""

Una descripción de la imagen

Se muestra si la imagen no carga, o para personas con discapacidad visual

🔗 Tipos de enlaces:

  • https://google.com

    Va a otra página web (externo)

  • /sobre-mi

    Va a otra página de TU sitio (interno)

  • #contacto

    Salta a una sección en la misma página

🖼️ Formatos de imagen comunes:

  • .jpg

    Para fotos (tamaño pequeño)

  • .png

    Para logos con fondo transparente

  • .svg

    Para iconos (nunca se pixelan)

enlaces-imagenes.htmlhtml
1<!-- Enlaces -->
2<a href="https:500 italic">//google.com">Ir a Google</a>
3<a href="/contacto">Página de contacto</a>
4<a href="#seccion">Ir a una sección de esta página</a>
5 
6<!-- Imágenes -->
7<img src="/images/logo.png" alt="Logo de la empresa">
8<img src="https:500 italic">//ejemplo.com/foto.jpg" alt="Descripción de la imagen">

💡 Importante: El atributo alt en imágenes es crucial para accesibilidad y SEO. Describe qué muestra la imagen para personas con discapacidad visual o si la imagen no carga.

Listas

📋 ¿Para qué sirven las listas?

Las listas son para mostrar grupos de cosas relacionadas. Como cuando escribes una lista de compras o pasos de una receta.

📝 Ejemplos del mundo real:

  • Lista de compras: leche, pan, huevos
  • Pasos de una receta: 1) mezclar, 2) hornear, 3) decorar
  • Menú de navegación: Inicio, Productos, Contacto
  • Lista de tareas: estudiar, hacer ejercicio, limpiar

Tipos de Listas

•

<ul> - Lista Desordenada (Unordered List)

Usa esto cuando el orden NO importa. Cada item tiene un bullet point (•).

Úsalo para:

  • Lista de ingredientes (no importa en qué orden los compres)
  • Características de un producto
  • Links de navegación
1.

<ol> - Lista Ordenada (Ordered List)

Usa esto cuando el orden SÍ importa. Cada item tiene un número.

Úsalo para:

  • Pasos de una receta (debes seguir el orden)
  • Instrucciones de instalación
  • Ranking o top 10
📖

<dl> - Lista de Definiciones (Definition List)

Para hacer un glosario o diccionario. Tiene términos <dt> y sus definiciones <dd>.

Úsalo para:

  • Glosario de términos técnicos
  • FAQ (preguntas y respuestas)
  • Especificaciones de producto (nombre: valor)

👁️ Así se ven:

Lista desordenada:

  • Manzanas
  • Naranjas
  • Plátanos

Lista ordenada:

  1. Mezclar ingredientes
  2. Hornear 30 minutos
  3. Dejar enfriar

Encabezado del sitio o de una sección. Suele contener logo, menú...

📝 Formularios

📋 ¿Qué son los formularios?

Los formularios son como encuestas en papel, pero en la web. Permiten que los usuarios te envíen información: registrarse, iniciar sesión, hacer comentarios, buscar cosas, etc.

📝 Ejemplos de formularios que usas todos los días:

  • ✅ Login de Facebook/Instagram: usuario y contraseña
  • ✅ Buscador de Google: la cajita donde escribes
  • ✅ Registro de Netflix: email, contraseña, método de pago
  • ✅ Comentarios de YouTube: el área de texto para comentar
  • ✅ Checkout de Amazon: dirección, tarjeta, confirmar compra

Sin formularios, las páginas web serían solo de "lectura". Los formularios las hacen interactivas.

Anatomía de un Formulario

🔍 Partes importantes:

<form>

La etiqueta contenedora. Todo el formulario va dentro de esta etiqueta.

action="/enviar"

La URL a donde se envían los datos cuando el usuario hace clic en "Enviar". Como la dirección del buzón de correo.

method="POST"

Cómo se envían los datos. POST = enviar de forma segura (para contraseñas, datos sensibles). GET = enviar en la URL (para búsquedas).

<input>

Los campos donde el usuario escribe o selecciona cosas. Hay muchos tipos diferentes.

<label>

La etiqueta que describe qué va en cada campo. Ayuda a usuarios y a accesibilidad.

<button type="submit">

El botón para enviar el formulario. Cuando haces clic, los datos se envían al servidor.

Tipos de Inputs (Campos)

Hay MUCHOS tipos de inputs. Cada uno está diseñado para un tipo específico de dato:

type="text"

Campo de texto simple

Para: nombres, apellidos, cualquier texto

type="email"

Campo de email

Valida que sea un email válido (con @)

type="password"

Campo de contraseña

Oculta lo que escribes (muestra •••)

type="number"

Solo números

Para: edad, cantidad, precio

type="checkbox"

Casilla de verificación ☑

Para: aceptar términos, múltiples opciones

type="radio"

Botón de opción ⭕

Para: elegir UNA opción (género, talla)

type="date"

Selector de fecha

Muestra un calendario para elegir fecha

type="file"

Subir archivo

Para: subir fotos, documentos, etc.

⚠️ Errores Comunes en HTML

Olvidar cerrar etiquetas

Toda etiqueta que abre debe cerrar: <p>texto</p>

Usar divs para todo

Usa etiquetas semánticas cuando sea posible: <header>, <nav>, <article>...

Olvidar el atributo alt en imágenes

Siempre incluye una descripción para accesibilidad y SEO.

No validar el HTML

Usa validator.w3.org para detectar errores.
