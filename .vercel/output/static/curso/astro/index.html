Módulo 6

Astro: 0 → Experto

Domina Astro, el framework moderno que prioriza el rendimiento y permite crear sitios ultra rápidos con múltiples frameworks.

¿Qué es Astro?

Astro es un framework web moderno que te permite construir sitios web rápidos enfocándose en el contenido.

Su filosofía principal: "Envía menos JavaScript al navegador"

¿Por qué Astro?

⚡

Ultra Rápido

Por defecto, genera HTML estático sin JavaScript innecesario.

🏝️

Islands Architecture

Hidrata solo los componentes interactivos que necesitas.

🔧

Agnóstico de Framework

Usa React, Vue, Svelte, Solid... ¡todos juntos si quieres!

📄

Content-First

Perfecto para blogs, documentación, portfolios, landing pages.

Componentes Astro

Los componentes .astro tienen una sintaxis especial dividida en dos partes:

  1. Component Script (entre ---): código que se ejecuta en el servidor
  2. Component Template: HTML con sintaxis similar a JSX

📦 Anatomía de un Componente Astro:

---

// JavaScript del servidor

const datos = "valor";

---

<!-- HTML del componente -->

<div>{ datos }</div>

<style>

  /* CSS con scope */

</style>

Los componentes Astro son reutilizables y se ejecutan en el servidor, generando HTML estático. Esto los hace súper rápidos.

Sistema de Rutas

Astro usa enrutamiento basado en archivos. Cada archivo en src/pages/ se convierte en una ruta. 

src/pages/

├── about.astro           → /about
├── blog/
│   ├── index.astro       → /blog
│   └── post-1.astro      → /blog/post-1
└── products/
    └── [id].astro        → /products/:id (dinámico)

Partial Hydration (Client Directives)

El secreto de la velocidad de Astro: por defecto, los componentes se renderizan a HTML estático sin JavaScript. Solo cargas JS cuando lo necesitas.

Client Directives

client:load

Carga JS inmediatamente al cargar la página.

client:idle

Carga JS cuando el navegador esté inactivo.

client:visible

Carga JS cuando el componente sea visible en pantalla.

client:media

Carga JS solo en ciertos tamaños de pantalla.

ejemplo-directives.astroastro
1---
2500">import Counter 500">from &#039;../components/Counter.tsx&#039;; 500 italic">// Componente React
3500">import Carousel 500">from &#039;../components/Carousel.tsx&#039;;
4---
5 
6<!-- Sin directive: solo HTML estático, sin JS -->
7<Counter />
8 
9<!-- Con client:load: carga JS inmediatamente -->
10<Counter client:load />
11 
12<!-- Con client:visible: carga JS solo cuando sea visible -->
13<Carousel client:visible />
14 
15<!-- Con client:idle: carga JS cuando el navegador esté libre -->
16<Counter client:idle />
17 
18<!-- Con client:media: solo en móviles -->
19<MobileMenu client:media="(max-width: 768px)" />
