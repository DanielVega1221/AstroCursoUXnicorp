Proyecto Final

Crea tu Proyecto desde Cero

Aprende paso a paso cómo crear un proyecto profesional con Astro, TypeScript, React Islands y desplegarlo en producción.

🎯 ¿Qué vamos a construir?

Crearemos un Portfolio Personal Interactivo que incluye:

  • ✅ Astro como framework base (SSG ultra-rápido)
  • ✅ TypeScript para type safety
  • ✅ React Islands para componentes interactivos
  • ✅ Tailwind CSS para estilos modernos
  • ✅ Responsive Design móvil y desktop
  • ✅ Dark Mode con persistencia
  • ✅ Deploy a Vercel (gratis)

⏱️ Tiempo estimado: 45-60 minutos

📦 Requisitos previos: Node.js 18+ instalado

Paso 1: Crear el Proyecto Base

1.1 Inicializar Astro

Abre tu terminal y ejecuta el comando de creación de Astro. Te hará algunas preguntas - aquí está lo que debes responder:

bash
1# Crear nuevo proyecto
2npm create astro@latest mi-portfolio
3 
4# Responde las preguntas así:
5# - Where should we create your 500">new project? → mi-portfolio
6# - How would you like to start your 500">new project? → Empty
7# - Install dependencies? → Yes
8# - Do you plan to write TypeScript? → Yes
9# - How strict should TypeScript be? → Strict
10# - Initialize a 500">new git repository? → Yes

💡 ¿Qué significa cada opción?

  • Empty: Proyecto limpio sin templates (aprenderás más)
  • TypeScript Strict: Máxima protección contra errores
  • Git repository: Para control de versiones

1.2 Entrar al proyecto

bash
1cd mi-portfolio

1.3 Instalar dependencias adicionales

Ahora instalemos React, Tailwind y otras herramientas que necesitamos:

bash

2npx astro add react
3 
4# Agregar Tailwind CSS
5npx astro add tailwind
6

✅ ¿Qué acabas de instalar?

  • React: Para componentes interactivos (islands)
  • Tailwind: Framework CSS utility-first
  • lucide-react: Iconos modernos y ligeros

7.3 Deploy a Vercel (GRATIS)

Opción 1: Desde la web (Recomendado para principiantes)

  1. Ve a vercel.com
  2. Haz clic en "Sign Up" e inicia sesión con GitHub
  3. Haz clic en "Add New..." → "Project"
  4. Selecciona tu repositorio "mi-portfolio"
  5. Vercel detecta Astro automáticamente
  6. Haz clic en "Deploy"
  7. ¡Espera 1-2 minutos y tu sitio estará online! 🎉

🔧 Troubleshooting (Problemas Comunes)

❌ Error: "Cannot find module"

Solución:

bash
1# Linux / macOS / Git Bash:
2rm -rf node_modules package-lock.json
3npm install
4 
5# Windows PowerShell:
6Remove-Item -Recurse -Force node_modules, package-lock.json
7npm install
8 
9# Windows CMD:
10rmdir /s /q node_modules
11del package-lock.json
12npm install

⚠️ React Island no se hidrata

Verificar:

  • Agregaste client:* directive? (client:load, client:visible, etc.)
  • El componente está en .tsx no .astro?
  • Exportaste con export default?

💡 Build funciona local pero falla en Vercel

Chequear:

  • Node version en Vercel (Settings → Node.js Version → 18.x o superior)
  • Variables de entorno si usas APIs
  • Los imports son case-sensitive en producción
