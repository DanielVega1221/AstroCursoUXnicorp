Módulo 3

CSS + Responsive + Diseño Moderno

Domina el arte de dar estilo a la web con CSS moderno, Flexbox, Grid, responsive design y animaciones.

¿Qué es CSS?

CSS (Cascading Style Sheets) es el lenguaje que da estilo visual a las páginas web. Controla colores, tamaños, posiciones, animaciones y mucho más.

Formas de Usar CSS

Hay 3 formas de aplicar CSS. La mejor práctica es usar CSS externo (archivo .css separado).

1. Inline

En el HTML directamente

❌ No recomendado

2. Interno

En etiqueta <style>

⚠️ Solo para demos

3. Externo

Archivo .css separado

✅ RECOMENDADO

formas-css.htmlcss
1<!-- 1. CSS Inline (no recomendado) -->
2<p style="color: blue; font-size: 18px;">Texto azul</p>
3 
4<!-- 2. CSS Interno (en el mismo HTML) -->
5<style>
6  p {
7    color: blue;
8    font-size: 18px;
9  }
10</style>
11 
12<!-- 3. CSS Externo (recomendado) -->
13<link rel="stylesheet" href="styles.css">

Anatomía de una regla CSS:

Flexbox: Layout en Una Dimensión

Flexbox es perfecto para alinear elementos en una dirección (fila o columna). Ideal para navbars, cards horizontales, centrado de elementos...

🎯 Cuándo usar Flexbox:

  • ✓ Barra de navegación horizontal
  • ✓ Centrar elementos vertical u horizontalmente
  • ✓ Distribuir espacio entre botones
  • ✓ Cards en fila que se adaptan
  • ✓ Footer con elementos espaciados

Demo Interactiva de Flexbox

Item 1
Item 2
Item 3
.container {
  display: flex;
  flex-direction: row;
  justify-content: flex-start;
  align-items: stretch;
  gap: 12px;
}

Propiedades Principales

Flexbox tiene dos tipos de elementos: el contenedor (padre con display: flex) y los items (hijos directos).

Contenedor (Padre)

  • flex-direction - Dirección
  • justify-content - Eje principal
  • align-items - Eje cruzado
  • gap - Espaciado

Items (Hijos)

  • flex-grow - Crecer
  • flex-shrink - Encoger
  • flex-basis - Tamaño base
  • flex - Shorthand
flexbox.csscss
1/* Contenedor Flex */
2.container {
3  display: flex;
4  
5  /* Dirección */
6  flex-direction: row; /* row | column | row-reverse | column-reverse */
7  
8  /* Alineación en el eje principal (horizontal en row, vertical en column) */
9  justify-content: center; /* flex-start | center | flex-end | space-between | space-around */
10  
11  /* Alineación en el eje cruzado (vertical en row, horizontal en column) */
12  align-items: center; /* flex-start | center | flex-end | stretch */
13  
14  /* Espaciado entre elementos */
15  gap: 16px;
16  
17  /* Envolver elementos */
18  flex-wrap: wrap; /* nowrap | wrap */
19}
20 
21/* Items Flex */
22.item {
23  /* Crecer para llenar espacio */
24  flex-grow: 1;
25  
26  /* Encogerse si es necesario */
27  flex-shrink: 1;
28  
29  /* Tamaño base */
30  flex-basis: 200px;
31  
32  /* Shorthand */
33  flex: 1 1 200px; /* grow shrink basis */
34}

CSS Grid: Layout en Dos Dimensiones

CSS Grid es ideal para layouts complejos en filas Y columnas simultáneamente. Perfecto para galerías, dashboards, layouts completos...

🎯 Cuándo usar Grid:

  • ✓ Galerías de imágenes
  • ✓ Layouts completos (header, sidebar, content, footer)
  • ✓ Dashboards con widgets
  • ✓ Tablas complejas de contenido
  • ✓ Cualquier diseño bidimensional

💡 Diferencia clave:

Flexbox

Una dimensión (fila O columna)

Grid

Dos dimensiones (filas Y columnas)

Demo Interactiva de Grid

1
2
3
4
5

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(2, 100px);
  gap: 16px;
}

Propiedades Principales

Grid divide el espacio en filas y columnas, creando una cuadrícula donde puedes colocar elementos.

grid.csscss
1/* Contenedor Grid */
2.container {
3  display: grid;
4  
5  /* Espaciado */
6  gap: 20px; /* espacio entre celdas */
7  row-gap: 10px; /* espacio entre filas */
8  column-gap: 20px; /* espacio entre columnas */
9}
10 
11/* Ejemplo 1: Columnas con proporciones */
12.grid-proporcional {
13  display: grid;
14  grid-template-columns: 1fr 2fr 1fr; /* 3 columnas: pequeña, grande, pequeña */
15  gap: 20px;
16}
17 
18/* Ejemplo 2: Columnas iguales con repeat */
19.grid-igual {
20  display: grid;
21  grid-template-columns: repeat(3, 1fr); /* 3 columnas del mismo tamaño */
22  gap: 20px;
23}
24 
25/* Ejemplo 3: Tamaños mixtos (fijo + flexible) */
26.grid-mixto {
27  display: grid;
28  grid-template-columns: 200px auto 200px; /* sidebars fijos, contenido flexible */
29  gap: 20px;
30}
31 
32/* Definir filas */
33.grid-con-filas {
34  display: grid;
35  grid-template-rows: 100px 200px auto; /* alturas específicas */
36  gap: 20px;
37}
38 
39/* Items Grid */
40.item {
41  /* Ocupar múltiples columnas */
42  grid-column: span 2; /* ocupa 2 columnas */
43  grid-column: 1 / 3; /* de columna 1 a 3 */
44  
45  /* Ocupar múltiples filas */
46  grid-row: span 2;
47}
48 
49/* Grid Areas (nombrado) */
50.container {
51  grid-template-areas:
52    "header header header"
53    "sidebar main main"
54    "footer footer footer";
55}
56 
57.header { grid-area: header; }
58.sidebar { grid-area: sidebar; }
59.main { grid-area: main; }
60.footer { grid-area: footer; }

Responsive Design

Responsive Design significa que tu sitio se adapta a cualquier tamaño de pantalla: móvil, tablet, desktop...

Media Queries

responsive.csscss
1/* Mobile First: estilos base para móvil */
2.container {
3  padding: 16px;
4  font-size: 14px;
5}
6 
7/* Tablet: 768px en adelante */
8@media (min-width: 768px) {
9  .container {
10    padding: 24px;
11    font-size: 16px;
12  }
13}
14 
15/* Desktop: 1024px en adelante */
16@media (min-width: 1024px) {
17  .container {
18    padding: 32px;
19    font-size: 18px;
20    max-width: 1200px;
21    margin: 0 auto;
22  }
23}
24 
25/* Orientación */
26@media (orientation: landscape) {
27  /* Estilos para vista horizontal */
28}
29 
30/* Dark mode */
31@media (prefers-color-scheme: dark) {
32  body {
33    background: #1a1a1a;
34    color: #ffffff;
35  }
36}

🎯 Cómo Practicar CSS

La mejor forma de aprender CSS es construyendo proyectos reales. Aquí tienes ejercicios progresivos:

🔰 Nivel Principiante

1. Navbar con Flexbox

Crea una barra de navegación horizontal con logo a la izquierda y links a la derecha. Usa justify-content: space-between

2. Card de Perfil

Diseña una tarjeta con imagen, nombre, descripción y botones. Practica centrado y espaciado.

3. Footer Responsive

Footer con 3 columnas en desktop, 1 columna en móvil. Usa media queries.

🚀 Nivel Intermedio

4. Galería con Grid

Galería de imágenes 3x3 en desktop, 2x2 en tablet, 1 columna en móvil. Usa grid-template-columns con media queries.

5. Dashboard Layout

Header, sidebar, contenido principal y footer usando Grid Areas. Practica layouts complejos.

6. Animaciones de Hover

Botones y cards con transiciones suaves al pasar el mouse. Usa transform y transition.

💎 Nivel Avanzado

7. Portfolio Completo

Sitio web de portfolio con hero, sección de proyectos (grid), about, y contacto. Todo responsive.

8. Dark Mode

Implementa tema oscuro usando variables CSS y JavaScript para toggle.

9. Animaciones Complejas

Loading spinner, animación de entrada de elementos, parallax scroll.
