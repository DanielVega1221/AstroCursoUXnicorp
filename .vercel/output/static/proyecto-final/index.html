Proyecto Final: Portfolio Premium

Construye tu portfolio profesional usando todo lo aprendido: Astro, React Islands, TypeScript, animaciones y mejores prácticas.

🎯 Objetivo del Proyecto

Crear un portfolio premium que muestre tus habilidades como desarrollador frontend. Será tu carta de presentación profesional para conseguir trabajo o clientes.

Requisitos del Portfolio

Tecnologías Obligatorias

  • ✓ Astro como base
  • ✓ React Islands para interactividad
  • ✓ TypeScript
  • ✓ Tailwind CSS (o CSS moderno)
  • ✓ Framer Motion para animaciones
  • ✓ Lenis para smooth scroll

Secciones Requeridas

  • ✓ Hero impactante
  • ✓ Sobre mí
  • ✓ Habilidades/Tecnologías
  • ✓ Proyectos (mínimo 3)
  • ✓ Experiencia/Formación
  • ✓ Formulario de contacto
  • ✓ Footer con links sociales

Funcionalidades

  • ✓ Dark/Light mode
  • ✓ Animaciones sutiles
  • ✓ Responsive perfecto
  • ✓ Navegación smooth
  • ✓ Lazy loading de imágenes
  • ✓ SEO optimizado

Extras Opcionales

  • Blog integrado
  • Testimonios/Reviews
  • Filtros de proyectos
  • Cursor custom
  • Transiciones de página
  • Analytics integrado

Guía Paso a Paso

1

Configurar el Proyecto

bash
1# Crear proyecto Astro
2npm create astro@latest mi-portfolio
3 
4# Instalar dependencias
5cd mi-portfolio
6npm install @astrojs/react @astrojs/tailwind tailwindcss
7npm install framer-motion @studio-freight/lenis
8npm install lucide-react
9 
10# Configurar integraciones
11npx astro add react tailwind
2

Crear el Layout Base

Crea un layout que incluya: navbar sticky, contenido principal, footer y sistema de temas.

3

Hero Section Impactante

Tu hero debe capturar atención inmediatamente. Incluye:

  • Tu nombre con animación
  • Título/rol con efecto typing o fade-in
  • CTA claro (botón de contacto)
  • Imagen o ilustración de calidad
  • Links a GitHub, LinkedIn, etc.
4

Sección Sobre Mí

Cuenta tu historia de forma breve y personal. Incluye una foto profesional y destaca qué te hace único como desarrollador.

5

Galería de Proyectos

Muestra 3-5 proyectos destacados. Para cada uno:

  • Imagen/mockup atractivo
  • Título y descripción concisa
  • Tecnologías utilizadas (badges)
  • Link a demo en vivo
  • Link a repositorio GitHub
  • Hover effects sutiles
6

Skills y Tecnologías

Muestra las tecnologías que dominas con iconos o badges. Agrupa por categorías (Frontend, Backend, Tools, etc.) para mejor organización.

7

Formulario de Contacto

Crea un formulario funcional con React. Opciones:

  • Formspree (gratis, sin backend)
  • EmailJS (envío directo por email)
  • API Route de Astro + servicio SMTP
  • Netlify Forms (si deployeas en Netlify)
8

Animaciones y Microinteracciones

Añade vida al portfolio con:

  • Fade-in al hacer scroll (Framer Motion)
  • Smooth scroll (Lenis)
  • Hover effects en cards y botones
  • Loading states
  • Transiciones suaves entre secciones
9

Optimización y SEO

  • Optimiza imágenes (WebP, lazy loading)
  • Meta tags adecuados
  • Open Graph para redes sociales
  • Lighthouse score alto (>90)
  • Sitemap.xml
  • robots.txt
10

Deploy en Vercel

bash
