Librerías para Astro

🎬 Animaciones

Framer Motion

La mejor librería de animaciones para React. Perfecta para React Islands en Astro.

npm install framer-motion

GSAP

Potente librería de animaciones profesionales. Timeline y control total.

npm install gsap

Motion One

Alternativa ligera y moderna a GSAP. Funciona con Web Animations API.

npm install motion

AOS (Animate On Scroll)

Anima elementos al hacer scroll. Simple y efectivo.

npm install aos

📜 Scroll Suave

Lenis

Smooth scroll moderno y performante. El más usado actualmente.

npm install @studio-freight/lenis

Locomotive Scroll

Scroll suave con parallax y efectos visuales incluidos.

npm install locomotive-scroll

🧩 Componentes UI

Swiper

Carousels y sliders modernos, touch-friendly y responsivos.

npm install swiper

Iconify

+150,000 iconos de todas las librerías populares en un solo lugar.

npm install @iconify/react

React Hook Form

Manejo de formularios performante y con validación.

npm install react-hook-form

Zod

Validación de datos con TypeScript. Perfecto para formularios y APIs.

npm install zod

🌳 Git Cheat Sheet

Configuración Inicial

git config --global user.name "Tu Nombre"

git config --global user.email "email@ejemplo.com"

git init - Iniciar repositorio

git clone url - Clonar repo

Básicos

git status - Ver estado

git add . - Agregar todos

git add archivo.js - Agregar uno

git commit -m "mensaje"

git push - Subir cambios

git pull - Bajar cambios

Branches

git branch - Ver branches

git branch nombre - Crear

git checkout nombre - Cambiar

git checkout -b nombre - Crear y cambiar

git merge nombre - Fusionar

git branch -d nombre - Borrar

Útiles

git log - Ver historial

git log --oneline - Resumido

git diff - Ver cambios

git reset --hard HEAD - Descartar todo

git stash - Guardar temporal

git stash pop - Recuperar

Tips para tu Carrera

✅ Checklist de Portfolio Profesional

  • ✓ Diseño limpio y profesional
  • ✓ Sección "Sobre mí" clara y concisa
  • ✓ 3-5 proyectos destacados con descripción
  • ✓ Tecnologías utilizadas en cada proyecto
  • ✓ Enlaces a demos en vivo y código (GitHub)
  • ✓ Formulario de contacto funcional
  • ✓ Links a redes sociales profesionales
  • ✓ CV descargable (PDF)
  • ✓ Responsive en todos los dispositivos
  • ✓ Rápido (Core Web Vitals optimizados)
  • ✓ SEO básico implementado

📝 Tips para el CV

  • • Máximo 2 páginas
  • • Resalta proyectos reales, no solo cursos
  • • Incluye enlaces a GitHub y portfolio
  • • Menciona tecnologías específicas
  • • Cuantifica logros cuando sea posible
  • • Revisa ortografía y formato

🚀 Cómo Conseguir tu Primer Trabajo

  1. 1. Construye proyectos reales - No solo tutoriales. Crea algo útil y único.
  2. 2. Contribuye a Open Source - GitHub muestra tu código y colaboración.
  3. 3. Networking - LinkedIn, Twitter/X, eventos locales de tech.
  4. 4. Practica entrevistas técnicas - LeetCode, HackerRank, etc.
  5. 5. Aplica estratégicamente - Personaliza CV para cada posición.
  6. 6. No te rindas - El primer trabajo es el más difícil. Persistencia.
